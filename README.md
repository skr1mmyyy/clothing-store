# VESSORE — сайт магазина

Статический сайт без сборки: открой `index.html` в браузере или залей папку на любой хостинг (GitHub Pages, Netlify, Vercel, Timeweb и т.п.).

## Структура
- `index.html` — каркас страницы (шапка, футер, корзина)
- `css/style.css` — стили
- `js/data.js` — **все данные магазина: товары, цены, категории, контакты, FAQ, таблица размеров**
- `js/app.js` — логика (каталог, страницы товаров, избранное, корзина, оформление)

## Как редактировать
- Товары, цены, фото, контакты — в `js/data.js`.
- Свои фото: положи в папку `img/` и укажи путь, например `images: ['img/hoodie-1.jpg', 'img/hoodie-2.jpg']`. Второе фото показывается при наведении.
- Промокоды — объект `PROMOS` в `js/app.js` (сейчас `VESSORE10` = −10%).

## Заказы
Сейчас заказ не уходит на сервер: после оформления покупатель видит текст заказа и отправляет его в Telegram или на почту из `data.js`.
Для приёма заказов/оплаты подключи бэкенд или Telegram-бота — место помечено комментарием в `submitOrder()` в `js/app.js`.
